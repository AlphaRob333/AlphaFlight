# Design & engineering fee schedule (starting values — Rob sets policy)

Store the live values in Supabase `rates` under `fee.*`. These are opening
numbers for a Central Florida design-only practice; Rob adjusts them, and
the agents never do.

| Tier | Includes | Base fee |
|---|---|---|
| Layout | Bay grid, plan/elevation sketch, component list, budget estimate. Not engineered. | $1,200 |
| Engineered | Layout + IFC/BIM model + load screening + drawing set stamped preliminary, ready for PE | $4,500 |
| Sealed | Engineered + PE review and seal (PE fee passed through at cost + 10%) + one site visit | $4,500 + PE |
| Program | Multi-scaffold or multi-phase program with a master model and per-phase issues | Quote; minimum $9,000 |

Adders: additional elevation $750; stair tower $600; dance floor / birdcage
$1,500; hanging or cantilever $2,500 (always Sealed tier); enclosure/
containment $800; hoist or loading bay $900; revision beyond two $450 each;
expedite (< 5 business days) +35%; theme-park submittal package (owner
forms, badging docs, sightline renders) $1,200.

Minimum engagement $1,200. Payment terms: 50% on order, 50% on issue for
review; program tiers monthly. Design fee is never discounted below
minimum by an agent; queue an approval.
